# Agent surface

This directory contains **operational instructions for agents working on Teaching**.

`AGENTS.md` defines the repository-wide pedagogical principles. Files in this directory turn those principles into task-specific generation and review rules.

Agents should:

1. read `AGENTS.md` first;
2. read the closest relevant file in this directory before generating or reviewing Teaching content;
3. treat public documentation as a human-facing explanation, not as a substitute for these operational rules;
4. preserve uncertainty instead of inventing missing pedagogical intent;
5. split large working artifacts by responsibility when several kinds of decisions begin competing inside one document, keeping a small coordinating surface rather than creating a monolith.
