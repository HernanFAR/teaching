# Asesoría

Teaching publica cómo trabaja.

La asesoría existe para cuando necesitas **criterio aplicado a tu situación**, no para desbloquear una metodología oculta.

- cómo separamos fuente y realización;
- cómo preservamos invariantes;
- cómo diseñamos recorridos;
- cómo usamos evidencia;
- cómo construimos distintas realizaciones desde una misma fuente.

Si eso te basta para trabajar por tu cuenta, perfecto.

## Asesoría 1:1

A veces el problema no es entender el enfoque, sino decidir qué hacer en un caso concreto.

Podemos revisar contigo una situación donde todavía no esté claro:

- qué objetivo necesita preservarse;
- qué presión existe realmente;
- qué partes todavía pueden permanecer simples;
- qué separación tiene una causa observable;
- qué alternativas siguen siendo defendibles;
- dónde conviene detenerse;
- cuál podría ser el siguiente cambio mínimo.

Esta revisión parte desde tu caso, no desde una plantilla que haya que imponer.

### Resultado esperado

Una sesión debería dejar algo parecido a:

```text
estado actual
+
presiones observadas
+
incertidumbres relevantes
+
opciones defendibles
+
siguiente cambio razonable, si existe
```

El mecanismo concreto para solicitar una sesión todavía está por definir.
