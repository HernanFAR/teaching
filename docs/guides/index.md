# Guías

Las guías serán recorridos orientados a un **objetivo concreto**.

A diferencia de una lección, una guía puede combinar varias ideas existentes para responder preguntas como:

- ¿cómo estructuro una API pequeña que probablemente crecerá?;
- ¿cómo preparo una aplicación para ser testeable?;
- ¿cómo separo dominio e infraestructura sin sobrearquitectura?;
- ¿cómo reconozco cuándo una abstracción realmente hace falta?

!!! warning "Todavía en construcción"
    Por ahora estamos construyendo primero las lecciones fundamentales. Cuando exista suficiente material, las guías podrán enlazarlas en recorridos prácticos sin duplicar su contenido.
