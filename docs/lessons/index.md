# Lecciones

Las lecciones son unidades autocontenidas para **entender un concepto**.

Cada una intenta responder tres preguntas:

1. ¿Qué problema aparece?
2. ¿Qué solución mínima lo resuelve?
3. ¿Qué nuevo concepto podemos nombrar después de haberlo experimentado?
